# Food Website

A simple and responsive food website built using **HTML, CSS, and JavaScript**. The project features a modern food-themed design with an easy and attractive user interface.

## Features

* Responsive food website
* Attractive food menu design
* Easy navigation
* Interactive JavaScript effects
* Clean HTML and CSS structure

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
Food-Website/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone the project.
2. Open `index.html` in your browser.
3. Enjoy the food website.
